# gui-client

This project is a *standalone client* which can be used in combination with the gui-server project to display feature models.

This client is based on Eclipse GLSP

## Build

### Using Gradle 
```bash
./gradlew build
```

### Initial Build
```bash
./gradlew yarnInstall
```

or

```bash
yarn install
```

### Every Build
```bash
./gradlew yarnBuild
```

or

```bash
yarn build
```
